# Shell Scripts

A collection of Bash shell scripts I use to automate repetitive tasks, 
manage systems, and speed up my development workflow.

## ✨ Features
- 🛠️ System administration helpers
- 📁 File & directory automation
- 🔄 Backup and sync scripts
- 📊 Log parsing and cleanup
- ⚡ Productivity shortcuts

## 📦 Requirements
- Bash 4.0+
- Linux, macOS, or WSL
- No external dependencies (unless noted in individual scripts)

## 🚀 Usage
```bash
chmod +x script.sh
./script.sh
